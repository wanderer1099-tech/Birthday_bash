BIRTHDAY SITE - HOW TO UPLOAD (GitHub Pages)

1. Unzip this folder. You will see: index.html, doodles/ (26 pictures), README.txt
2. Add her photos NEXT TO index.html (same folder, not inside doodles):
     bday1.jpg  bday2.jpg  bday3.jpg   -> 3 photos shown on the birthday screen
     photo1.jpg ... photo6.jpg         -> the 6 polaroids
   (lowercase names, .jpg. If a photo is missing, an emoji frame shows instead.)
3. On GitHub: your repo -> Add file -> Upload files -> drag index.html, the doodles folder
   and the photos -> Commit changes.
4. Settings -> Pages -> Deploy from branch -> main -> / (root) -> Save.
5. Share your plain link on WhatsApp. To preview the birthday part early, add #birthday
   at the end of the link (don't send her that version).
